# 输出语言

默认使用简体中文与用户交流，并生成文档的标题、章节、正文、表格说明、
需求与来源说明、设计方案、实施计划、验证报告和文档补丁。单独调用任一
阶段 Skill 时也适用，不依赖先调用 Coding SOP。

用户明确指定输出语言时，以用户要求为准，不为语言选择再次询问。
英文的 Skill 指令、上游方法或示例不代表输出也应使用英文。

保持代码标识符、命令、文件路径、URL、JSON 字段、枚举值、错误码、精确
ArtifactRef 和 Git identity 原样；必要的原文引用、专有名词可以保留。
不要翻译已批准文档的内容或重新生成其摘要来冒充原来的精确引用。修改已有
文档时遵守用户指定的范围，不因默认语言而全文翻译或重写历史记录。

Clarify 的 `requirements.write` 默认使用 `document_language: zh-CN`，可以省略
该字段；用户明确要求英文时传 `document_language: en`。Writer 仅负责固定标题
和来源标签，不翻译调用者传入的 `title`、`clarified_requirements` 或 `supports`；
Agent 必须按用户要求生成这些自然语言内容。Loader 兼容已有英文文档，
语言变化不影响来源校验和精确审批要求。
