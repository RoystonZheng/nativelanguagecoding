# RDS 安全查数

## 适用范围

用于通过组织批准的只读入口核对测试或生产数据库中的少量数据。它不是数据导出、离线分析或数据修改流程。

## 来源和时效

这是公共模板，不绑定任何公司平台。查询入口可能限制语句类型、执行时长和结果行数，实际阈值以项目所在组织的平台提示和安全规范为准。

## 必要输入

- 查询目的和要验证的业务口径。
- 目标环境 `<ENV>`、数据库服务 `<DB_SERVICE>`、数据库 `<DATABASE>` 和表 `<TABLE>`。
- 时间范围、业务主键或其他高选择性过滤条件。
- 字段敏感等级、最小必要返回列和结果使用方式。

## 安全边界

- 默认只执行 `SELECT`。需要 `EXPLAIN`、导出或其他操作时使用组织批准的入口。
- 使用只读账号，不使用读写账号绕过限制。
- 不执行 `UPDATE`、`DELETE`、`INSERT`、DDL、存储过程或多语句脚本。
- 不查询无边界的全表，不返回大结果集，不用查询平台替代离线计算。
- 只读取完成目标所需的字段。个人信息、凭证和敏感业务数据必须最小化、脱敏，且不得写入文档、代码、日志或回复。
- 所有生产查询都应保留审计记录，不尝试绕过审计。

## 编写查询

1. 先确认表名、字段名、字段语义和数据时间口径。
2. 显式列出返回字段，不使用 `SELECT *`。
3. 使用主键、唯一键或已确认索引的前缀作为主要过滤条件。
4. 加入明确时间范围和 `LIMIT`。先用极小范围验证，再按需要扩大。
5. 避免对索引列做函数、隐式类型转换或前导模糊匹配。
6. `IN` 参数保持小规模，必要时拆分查询。
7. 对潜在重查询先检查执行计划；如果当前入口不支持，停止并选择批准的分析入口。
8. 在执行生产或敏感查询前，向用户展示环境、库表、时间范围、返回字段和 SQL 摘要。

## 执行查询

1. 打开组织批准的只读查询入口。
2. 选择目标服务、数据库和只读账号，逐项核对环境。
3. 粘贴一条只读 SQL，再次检查过滤条件和 `LIMIT`。
4. 执行并观察平台返回。超时、空结果或平台拒绝不等于业务事实为空。
5. 只记录回答问题所需的汇总或脱敏结论，不复制整行敏感记录。

## 结果验证

- 用业务主键、时间边界和已知样本交叉检查结果。
- 区分“确实没有数据”“查询条件错误”“只读副本延迟”“查询超时”和“权限不足”。
- 需要统计时优先返回聚合结果；需要样本时控制在最小行数。
- 执行记录包含查询目的、环境、脱敏后的 SQL 摘要、时间范围、执行时间和结果行数。手机号、订单号、用户 ID 等条件字面量也必须参数化或替换为 `<REDACTED>`。

## 失败处理

- 只读入口不可用：停止重试，按组织流程申请访问或联系数据库负责人。
- 查询超时：缩小时间范围、补充索引条件或转离线查询，不通过移除限制强行执行。
- 无权限：申请最小只读权限，不改用更高权限账号。
- 结果异常：核对库、表、环境、时区、只读副本延迟和业务口径，再判断数据问题。
- 查询是只读操作，无需回滚；若误执行了写操作，立即按事故流程升级。

## 项目化补充

在具体项目中补充查询平台入口、权限申请方式、敏感字段分级、审计要求和样例 SQL 模板。
