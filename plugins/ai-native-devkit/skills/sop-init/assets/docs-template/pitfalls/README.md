# 常见问题

本目录记录已经确认、可能重复发生且具有复用价值的问题及其规避方法。

## 文件索引

| 文件 | 内容 | 什么时候读取 |
|---|---|---|
| `database.md` | 数据库、迁移、事务和索引问题 | 遇到数据库问题时 |
| `openapi.md` | 鉴权、签名、参数和错误码问题 | OpenAPI 调用失败时 |
| `configuration.md` | 配置中心、环境变量和密钥问题 | 配置未生效时 |
| `deployment.md` | 构建、启动、发布和运行环境问题 | 部署或启动失败时 |

## 维护规则

### 命名规则

分类文件按问题领域命名。通常在已有分类文件中追加问题，只有出现新的独立领域时才新增分类文件。

### 新增和更新规则

只记录原因已经确认、可能重复发生且解决方法可复用的问题。一次性故障和未经验证的猜测不沉淀。

## 问题模板

每条问题包含问题名称、症状、触发条件、原因、解决方法、验证方式和相关资料。
